The most useful shortcuts are in the Screenplay mode, where you spend the most time at the
keyboard.

## Screenplay editor

| Shortcut | Effect |
| --- | --- |
| **Ctrl+Shift+M** | Switch between the styled editor and the raw Fountain text |
| **Tab** / **Shift+Tab** | Cycle the current block's type, and lock it |
| **Enter** | New block, in the type that normally follows |
| **Shift+Enter** | New block, keeping the same type |

The usual editing gestures — **Ctrl+C**, **Ctrl+X**, **Ctrl+V**, **Ctrl+Z** — work as everywhere.
Copy-paste inside the app preserves block types.

:::note

Undo history belongs to the surface you are on: switching between the styled editor and the raw
text starts a fresh history. Finish an edit before you switch.

:::

## Elsewhere in the application

Most actions in the other modes go through the toolbar, the menus and the right-click rather than
dedicated shortcuts. Each mode's **⋮** menu gathers its display settings and the **Reset panel
layout** command.
