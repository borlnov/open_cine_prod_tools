# Exporting your work

This page gathers, mode by mode, every document the application can produce. The general
principle — the **Export** control, the panel of cards, the "Save As" dialog — is described in
[Exporting, in short](../concepts/exporting-overview.md).

## Formats

The application exports three formats today: **PDF** (documents to print or circulate), **XLSX**
(editable spreadsheet workbooks) and **`.fountain`** (screenplay as plain text).

## The documents, mode by mode

### Screenplay

- **Screenplay PDF** — the script typeset as pages, with the title page and explicit scene
  numbers. *(PDF)*
- **Fountain screenplay** — the screenplay as Fountain text. *(.fountain)*

### Breakdown

- **Breakdown sheets** — one sheet per scene. *(PDF)*
- **Breakdown workbook** — a *Scenes* sheet and a filterable *Breakdown* sheet. *(XLSX)*

### Shot list

- **Scenario coverage** — the screenplay printed with a coloured bar in the margin beside each
  covered passage; options for format, title page, scene numbers, legend, summary. *(PDF)*
- **Shot list workbook** — one row per shot, all its fields. *(XLSX)*

### Resources

- **Resources workbook** — four sheets: people, roles, locations, elements. *(XLSX)*
- **Contact list** — the crew and cast on one circulated sheet. *(PDF)*

### Schedule

- **Call sheets** — general and named. *(PDF)*
- **Shooting plan** — summary grids and a per-day agenda. *(PDF)*
- **Shooting plan** — the same as a spreadsheet, with a chronology. *(XLSX)*
- **Day Out of Days** — the cast schedule. *(PDF)*
- **One-line schedule** — one line per scene in shooting order. *(PDF)*
- **Sides** — a day's screenplay pages. *(PDF)*

### Budget

- **Quote** — the CNC nomenclature, poste by poste; offers a VAT basis. *(PDF)*
- **Financing plan** — what pays for the film. *(PDF)*
- **Cash journal** — every entry, with its voucher number. *(XLSX)*
- **Financial report** — the quote against what is paid and committed. *(PDF)*

## Options and scope

- Some documents open an **options dialog** before saving — for example, the scenario coverage
  offers the page format, the title page, the scene numbers, a legend page and a summary page.
- An export tied to an episode produces the **selected episode**, and the suggested name includes
  an episode tag as soon as the project holds several.

## Sending the whole project

To pass the complete project to someone, export it as an **`.ocptz` package** — see [Exporting,
in short](../concepts/exporting-overview.md).
