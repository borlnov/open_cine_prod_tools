# L'aperçu en lecture seule

## Quand il s'active

Le projet passe en **lecture seule** dès que vous **prévisualisez une version** : vous avez
cliqué sur la carte d'une version pour la regarder sans rien engager. Le contenu est présenté
exactement tel qu'il avait été capturé.

## Ce que vous voyez

- Un **bandeau de lecture seule** sur toute la largeur, entre la barre d'outils et les
  panneaux, qui nomme la version consultée.
- Une pastille **Lecture seule** à l'endroit où figure d'ordinaire l'indicateur de
  modifications non enregistrées.

## Ce que vous pouvez faire, et ne pas faire

- **Vous pouvez** tout ce qui ne fait que lire : parcourir les panneaux et les statistiques,
  chercher, consulter les agendas et les horaires calculés, et **exporter** (l'aide reste elle
  aussi disponible). Un export écrit alors exactement ce qui est à l'écran.
- **Vous ne pouvez pas** écrire : les champs modifiables, les boutons d'ajout ou de
  suppression, les sélecteurs disparaissent tout simplement — ils ne sont pas grisés, ils sont
  retirés. Toute modification à peine commencée est effacée en entrant dans l'aperçu.

## Comment en sortir

Le bandeau propose deux issues :

- **Partir de cette version** — la restaurer, votre façon de repartir d'un état plus ancien ;
- **Revenir à la version actuelle** — quitter l'aperçu sans rien changer.
