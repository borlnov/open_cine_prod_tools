# Raccourcis clavier

Les raccourcis les plus utiles se trouvent dans le mode Scénario, où l'on passe le plus de temps
au clavier.

## Éditeur de scénario

| Raccourci | Effet |
| --- | --- |
| **Ctrl+Maj+M** | Basculer entre l'éditeur stylé et le texte Fountain brut |
| **Tab** / **Maj+Tab** | Faire défiler le type du bloc courant, et le verrouiller |
| **Entrée** | Nouveau bloc, dans le type qui suit normalement |
| **Maj+Entrée** | Nouveau bloc, en gardant le même type |

Les gestes d'édition habituels — **Ctrl+C**, **Ctrl+X**, **Ctrl+V**, **Ctrl+Z** — fonctionnent
comme partout. Le copier-coller interne conserve les types de blocs.

:::note

L'historique d'annulation appartient à la surface où vous êtes : basculer entre l'éditeur stylé
et le texte brut repart d'un historique neuf. Terminez une modification avant de changer.

:::

## Ailleurs dans l'application

La plupart des actions des autres modes passent par la barre d'outils, les menus et le clic
droit plutôt que par des raccourcis dédiés. Le menu **⋮** de chaque mode regroupe ses réglages
d'affichage et la commande **Réinitialiser la disposition** des panneaux.
