## Introduction

Open Cine Prod Tools is an open-source suite of production tools for film making. The first
production mode being built is a screenplay editor; more production modes will follow over time.

The screenplay editor is currently in development.

## Development

This project ships with a devcontainer that provides a ready-to-use Flutter toolchain. Open the
repository in the devcontainer, then run:

```bash
flutter pub get
flutter run -d linux
```
